# ADR-001: исполняемый контракт Telegram runtime

Статус: принят локально
Дата: 2026-07-28

## Решение

Runtime исполняет неизменяемый `.funnel 3.0.0` и импортирует парсер, handles,
scoring, операции переменных, условия, подстановку и базовую валидацию
непосредственно из `../src/model` конструктора. Второй реализации этих правил
нет.

Координаты `editor` сохраняются при импорте и обратном экспорте, но runtime их
не использует.

## Безопасные defaults и импорт `2.0.0`

Простые файлы `2.0.0` мигрируют до `3.0.0` с пустым справочником переменных.

- Платёжный провайдер: `unconfigured`.
- Тип продукта: `other`.
- Валюта: `RUB`.
- Сумма: `product.price × 100`, но она не используется до явной настройки
  провайдера администратором.
- Выдача: существующий `product.assetId`, если он задан.
- Повторная покупка: повторная выдача без нового списания.
- Напоминания: два безопасных runtime-правила — незавершённый тест через два
  часа и незавершённый этап через сутки; оба ограничены `bot.reminders.maxCount`
  и тихими часами.

Ни один старый продукт не может списать реальные деньги только на основании
импорта. Публикация версии с используемым продуктом блокируется, пока provider
не настроен, либо администратор не использует явный локальный `mock`.

## Семантика исходов

| Блок | Исходы |
| --- | --- |
| Start | `next` автоматически |
| Message | branch-button ID; при отсутствии branch — `next` |
| Media | `next` после отправки/разрешённой заглушки |
| Variables | применить действия сверху вниз, затем `next` |
| Condition | `true` или `false` по общему правилу конструктора |
| Timer | `next` из durable job |
| Test | ID выбранного основного/комбинированного результата |
| Form | `submitted`, `cancelled` |
| Consent | `accepted`, опционально `declined` |
| Product | `paid`, `failed`, `already_purchased`, опционально `skip` |
| External link | `next` только через подтверждённый redirect или локальную кнопку |
| End | исходов нет |

URL- и product-кнопки сообщения/результата являются боковыми действиями.
Branch-кнопка результата использует handle выбранного результата, поэтому
несколько таких CTA ведут в одну ветку.

## Версии

Версия хранится как raw JSON плюс SHA-256. Сессия навсегда привязана к
`funnel_versions.id`. Публикация или rollback меняет только версию для новых
стартов.
