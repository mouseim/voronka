# ADR-003: простая логика `.funnel` 3.0

Статус: принято  
Дата: 2026-07-28

## Контекст

Формат 2.0 убрал программируемую модель версии 1.x и сделал конструктор
понятным без технической подготовки. Для персональных путей всё же нужны два
базовых действия: сохранить простое значение и выбрать ветку по этому значению.

## Решение

Формат `3.0.0` добавляет ровно две исполняемые сущности:

- блок `variable` с упорядоченным списком простых операций;
- блок `condition` с одним правилом и выходами `true` / `false`.

Переменные объявляются в одном справочнике документа. Поддерживаются только
типы `text`, `number` и `boolean`. Операции ограничены присваиванием, изменением
числа, переключением логического значения и сбросом к начальному значению.

Условие сравнивает одну переменную. Наборов правил, вложенных групп, формул,
вычисляемых выражений и произвольного кода нет.

Текущие значения живут только в сессии прохождения. Стабильный код переменной
можно использовать в пользовательском тексте как `{{variable_key}}`.

## Совместимость

Файлы `2.0.0` автоматически мигрируют в `3.0.0`: добавляется пустой массив
`variables`, остальные данные сохраняются. Файлы старой расширенной версии
`1.x` по-прежнему отклоняются.

## Исполнение

Предпросмотр конструктора и Telegram runtime используют общие функции:

- создание начального состояния;
- последовательное применение операций;
- проверка условия;
- безопасная текстовая подстановка.

Блоки `variable` и `condition` являются автоматическими переходами. Runtime
проверяет автоматические циклы и ограничивает число переходов, чтобы ошибочная
схема не зациклила бота.
