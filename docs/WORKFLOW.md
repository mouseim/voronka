# Проверка упрощённого конструктора

## Основной сценарий

1. Открыть полное демо.
2. Убедиться, что в библиотеке ровно 10 понятных блоков и нет условий, переменных и формул.
3. Выбрать сообщение «Приветствие».
4. Добавить ветвящую кнопку — на карточке должен появиться новый выход.
5. Переименовать кнопку — существующая стрелка должна сохранить связь.
6. Удалить связанную кнопку — должно появиться предупреждение.
7. Соединить оставшиеся выходы и запустить проверку.

## Тест

1. Открыть вкладку «Тесты».
2. Изменить вопрос, добавить ответ и баллы по двум шкалам.
3. Добавить шкалу и убедиться, что она появилась в scoring.
4. Открыть «Результаты», проверить основные и комбинированные тексты.
5. В «Проверить прохождение» ответить на вопросы.
6. Сверить баллы, динамические максимумы, проценты и объяснение результата.

## Бот и источники

1. Открыть вкладку «Бот».
2. Заполнить username без токена.
3. Создать две ссылки с одинаковыми источником и кампанией.
4. Убедиться, что коды уникальны, а готовые ссылки начинаются с `https://t.me/`.
5. Открыть статистику → «Источники».
6. Проверить карточку с данными и честное пустое состояние для ссылки без снимка.

## Файл и версия

1. Нажать «Скачать файл для бота».
2. Импортировать полученный `.funnel`.
3. Проверить кнопки, стрелки, scoring, продукты, ссылки, статистику и координаты.
4. Создать новую версию через «Ещё».
5. Подтвердить сброс статистики и убедиться, что исходная версия не изменилась.
6. Попробовать импортировать файл `1.x` и проверить сообщение о несовместимости.

## Автоматические проверки

```bash
npm test
npm run build
npm run test:e2e
```
