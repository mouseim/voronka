# Проверка основной версии

## Быстрый ручной путь

1. На стартовом экране откройте «Полное демо».
2. На схеме найдите блок по названию, выделите несколько блоков с `Shift`, проверьте выравнивание и отмену.
3. Откройте «Разделы» и проверьте переменные, семь шкал теста, результаты, медиа и продукт.
4. В «Проверке» убедитесь, что у демо нет ошибок; советы о неиспользуемых демонстрационных ресурсах допустимы.
5. Запустите предпросмотр, выберите сохранённый сценарий и пройдите до результата `S1`.
6. Откройте статистику и переключите вкладки; выгрузите контакты или заявки в CSV.
7. Сохраните проект, создайте новую версию и сравните её с предыдущей.
8. Импортируйте `public/fixtures/demo-diagnostika-v0.1.funnel` и убедитесь, что показано уведомление о миграции.

## Автоматическая проверка

```bash
npm test
npm run build
```

Тесты покрывают текущую схему, миграцию и изоляцию аналитики, round-trip, граф, безопасные условия и формулы, scoring, детерминированный симулятор и статистику версий.
